# 1. java+vue实现可配置报表平台

实现一个“可配置报表平台”，让业务人员不用再单独开发页面，就能通过配置 SQL 快速生成一个新的报表界面，并支持在线查询和 Excel 导出。

**核心需求点**

1. 报表配置管理
   提供一个报表配置页面，支持新增、编辑、删除、查看报表配置。

2. SQL 配置能力
   每个报表都可以配置一段查询 SQL，系统按配置执行并返回结果。

3. 列展示配置，支持配置：

   - SQL 返回字段名
   - 页面表格展示标题
   - 列宽等基础展示属性
     这样同一个数据库字段可以用更业务化的标题展示给用户。

4. 多报表支持
   系统支持同时维护多个 SQL 报表配置，每个报表都是独立的配置对象，互不影响。

5. 报表唯一标识
   每个报表自动或手动生成唯一 Code，作为该报表的访问标识。

6. 动态页面生成
   系统根据固定路由 + code 的方式生成访问地址，例如：

   `/report/sql/{code} `

   用户访问不同 code，看到的是对应报表的数据页面。

7. 动态菜单展示
   已启用的报表应自动出现在系统菜单中，菜单名称取报表名称，点击后进入对应报表页面。

8. Excel 导出
   报表页面支持将当前报表结果导出为 Excel，导出列头应与页面展示标题一致。

9. 数据源选择
   报表配置时支持选择执行 SQL 的数据源，满足不同业务库的报表接入需求。

10. 报表启停状态
    每个报表应支持“启用/停用”状态：

- 启用：可展示在菜单中并允许访问
- 停用：不展示或不允许执行

##  3. 核心设计思路

## 1. 报表配置持久化
新增 sys_sql_report 表，保存 code、报表名称、数据源、SQL、列配置 JSON、状态等信息。每条配置对应一个报表页面。

```sql
CREATE TABLE IF NOT EXISTS sys_sql_report (
    id BIGINT NOT NULL COMMENT '主键ID',
    code VARCHAR(64) NOT NULL COMMENT '报表Code',
    report_name VARCHAR(100) NOT NULL COMMENT '报表名称',
    data_source_name VARCHAR(64) NOT NULL DEFAULT 'master' COMMENT '数据源名称',
    sql_text LONGTEXT NOT NULL COMMENT '执行SQL',
    columns_json LONGTEXT NULL COMMENT '列配置JSON',
    status CHAR(1) NOT NULL DEFAULT '0' COMMENT '状态（0正常 1停用）',
    remark VARCHAR(500) NULL COMMENT '备注',
    create_by BIGINT NULL COMMENT '创建者',
    create_time DATETIME NULL COMMENT '创建时间',
    update_by BIGINT NULL COMMENT '更新者',
    update_time DATETIME NULL COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_sys_sql_report_code (code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='可配置SQL报表';

```

## 2. 前端只传 code，后端执行已保存 SQL

前端访问 /report/sql/{code}，后端根据 code 查询配置并执行 SQL。这样避免前端直接传任意 SQL 执行。

1. 接口设计

   ```java
   @PostMapping("/execute/{code}")
   public R<SqlReportResultVo> execute(@PathVariable String code, @RequestBody SqlReportExecuteBo bo)
   ```

2. SQL 执行核心：

   ```java
   public SqlReportResultVo execute(String code, SqlReportExecuteBo bo) {
       SqlReport report = getExecutableReport(code);
       String sql = validateSql(report.getSqlText());
   
       JdbcTemplate jdbcTemplate = new JdbcTemplate(resolveDataSource(report.getDataSourceName()));
       long total = queryTotal(jdbcTemplate, sql);
   
       RawQueryResult rawResult = queryRows(
           jdbcTemplate,
           buildPageSql(resolveDataSource(report.getDataSourceName()), sql, pageNum, pageSize)
       );
       return buildResult(report, rawResult, total);
   }
   ```

   ```java
   private RawQueryResult queryRows(JdbcTemplate jdbcTemplate, String sql) {
       return jdbcTemplate.query(sql, rs -> {
           ResultSetMetaData metaData = rs.getMetaData();
           int columnCount = metaData.getColumnCount();
           List<String> labels = new ArrayList<>();
           for (int i = 1; i <= columnCount; i++) {
               labels.add(metaData.getColumnLabel(i));
           }
   
           List<Map<String, Object>> rows = new ArrayList<>();
           while (rs.next()) {
               Map<String, Object> row = new LinkedHashMap<>();
               for (int i = 1; i <= columnCount; i++) {
                   row.put(labels.get(i - 1), rs.getObject(i));
               }
               rows.add(row);
           }
           return new RawQueryResult(labels, rows);
       });
   }
   private record RawQueryResult(List<String> columnLabels, List<Map<String, Object>> rows) {
   }
   ```

## 4. 动态菜单生成

后端在 /system/menu/getRouters 返回菜单时，自动把启用的报表配置拼成路由：

```
/report/sql/{code}
```

```java
@GetMapping("/getRouters")
public R<List<RouterVo>> getRouters() {
    List<SysMenu> menus = menuService.selectMenuTreeByUserId();
    List<RouterVo> routers = menuService.buildMenus(menus);
    routers.addAll(sqlReportService.buildReportRouters());
    return R.ok(routers);
}
```

```java
@Override
public List<RouterVo> buildReportRouters() {
    RouterVo parent = new RouterVo();
    parent.setName("SqlReportCenter");
    parent.setPath("/report");
    parent.setComponent("Layout");
    parent.setRedirect("noRedirect");
    parent.setAlwaysShow(true);
    parent.setMeta(new MetaVo("可配置报表", "DataAnalysis", true));

    List<RouterVo> children = new ArrayList<>();
    RouterVo config = new RouterVo();
    config.setName("SqlReportConfig");
    config.setPath("sql-config");
    config.setComponent("report/sqlReportConfig/index");
    config.setMeta(new MetaVo("报表配置", "Setting", true));
    children.add(config);

    LambdaQueryWrapper<SqlReport> wrapper = Wrappers.lambdaQuery(SqlReport.class)
        .eq(SqlReport::getStatus, ENABLED)
        .orderByAsc(SqlReport::getReportName)
        .orderByAsc(SqlReport::getCode);
    List<SqlReport> reports = sqlReportMapper.selectList(wrapper);
    for (SqlReport report : reports) {
        RouterVo child = new RouterVo();
        child.setName("SqlReport" + routeNameSuffix(report.getCode()));
        child.setPath("sql/" + report.getCode());
        child.setComponent("report/sqlReport/index");
        child.setMeta(new MetaVo(report.getReportName(), "Tickets", true));
        children.add(child);
    }

    parent.setChildren(children);
    return List.of(parent);
}
```
